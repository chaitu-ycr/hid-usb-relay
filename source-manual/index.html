    HID USB Relay Controller Module

    Provides an object-oriented interface for controlling HID USB relay devices via command-line executable. Supports multiple relay devices with proper error handling, validation, and reusability.

    Example

    relay = USBRelayDevice() # Default device relay.turn_on(1) relay.get_state() {'R1': 'ON', 'R2': 'OFF'}

    specific = USBRelayDevice(device_id='HURTM') specific.turn_on_all()

    Context manager pattern

    with USBRelayDevice('HURTM') as relay: ... relay.turn_on_all()

    USBRelayDevice(device_id=None, executable_path=None, timeout=DEFAULT_TIMEOUT)

    Interface for controlling a USB relay device.

    Supports context manager protocol for resource management patterns.

    Attributes:

    Name Type Description
    device_id

    Optional device ID. If None, uses default device.
    Example

    relay = USBRelayDevice(device_id='HURTM') relay.turn_on(1) relay.get_state() {'R1': 'ON', 'R2': 'OFF'}

    with USBRelayDevice('HURTM') as relay: ... relay.turn_on_all()
